# Learn about Connect_CMP

## Overview

**Connect_CMP** is a role-based **College Management System (Android app)** that streamlines academic operations such as student/faculty management, notice dissemination, and attendance tracking. The app is built using **Java, XML, and Firebase**, with separate modules for **Admin, Teacher, and Student**.

---

## Prerequisites

- Basic knowledge of **Java & OOP concepts**
- **Android Studio** installed
- Understanding of **XML layouts & Fragments**
- Basic knowledge of **Firebase (Auth + Database)**

---

## Learning Objectives

By building and exploring this project, you will learn how to:

- Implement **role-based authentication & dashboards**
- Connect Android apps to **Firebase Realtime Database**
- Design apps using **Fragments and modular architecture**
- Implement an **Attendance Management System**
- Visualize data using **charts/analytics**
- Structure data using **unique Firebase IDs (UIDs)**

---

## Main Modules

### 1. Admin Module

- Add/View Students  
- Add/View Faculty  
- Create & Publish Notices  
- Manage Users  

---

### 2. Teacher Module

- View Student List  
- Mark Attendance (Subject-wise / Date-wise)  
- View Class-wise Reports  

---

### 3. Student Module

- View Notices  
- Check Attendance Percentage  
- View Analytics (Pie / Bar Chart)  

---

## Technologies Used

- **Java & XML (Android)**
- **Firebase Authentication**
- **Firebase Realtime Database**
- **Firebase Storage**
- **MPAndroidChart (for analytics)**
- **Git & GitHub**
